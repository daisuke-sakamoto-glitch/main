# Slack タスク抽出 Skill

Slackのメッセージを取得し、その中からタスク（やるべきこと・依頼・TODO）を抽出して整理する。

## 実行手順

### 1. Slackメッセージの取得

以下のコマンドでSlackメッセージを取得する。ユーザーが引数を指定した場合はそれを使用する。

```bash
python slack_task_extractor.py $ARGUMENTS
```

引数が未指定の場合のデフォルト:
```bash
python slack_task_extractor.py --days 1 --include-threads
```

利用可能なオプション:
- `--channels <name,...>`: 特定チャンネルのみ（カンマ区切り）
- `--days <N>`: 直近N日分（デフォルト: 1）
- `--mentions-only`: 自分宛メンションのみ
- `--dm`: DMも含める
- `--include-threads`: スレッド返信も取得
- `--extract-tasks`: スクリプト内蔵のキーワード検出でタスクを自動抽出
- `--post-to <channel>`: 結果をSlackチャンネルに投稿
- `--output json`: JSON形式で出力

### 2. タスクの抽出

取得したメッセージを分析し、以下の基準でタスクを抽出する:

**タスクと判定する基準:**
- 明示的な依頼・指示（「〜してください」「〜お願いします」「〜頼みます」）
- 質問・確認依頼（「〜確認してもらえますか？」「〜教えてください」）
- 期限付きの言及（「〜までに」「今週中に」「明日までに」）
- アクションアイテム（「TODO:」「対応:」「要対応」）
- レビュー依頼（「レビューお願いします」「PRお願いします」「確認お願い」）
- メンション付きの依頼（自分宛の@メンション）
- 未解決の質問（返信がないか、解決済みでない質問）

**タスクでないもの（除外）:**
- 雑談・挨拶
- 情報共有のみ（対応不要の通知）
- 既に完了が報告されているもの
- botの自動投稿

### 3. 出力フォーマット

抽出したタスクを以下の形式で整理して表示する:

#### 優先度の判定基準:
- **高**: 期限が明日以内、緊急の文言あり、上長からの依頼
- **中**: 期限が今週中、通常の依頼
- **低**: 期限の記載なし、FYI的な対応依頼

#### 出力テンプレート:

```
## Slackから抽出したタスク一覧

### 🔴 高優先度
| # | タスク | 依頼者 | チャンネル | 期限 |
|---|--------|--------|------------|------|
| 1 | タスク内容 | @名前 | #channel | 期限 |

### 🟡 中優先度
| # | タスク | 依頼者 | チャンネル | 期限 |
|---|--------|--------|------------|------|
| 2 | タスク内容 | @名前 | #channel | - |

### 🟢 低優先度
| # | タスク | 依頼者 | チャンネル | 期限 |
|---|--------|--------|------------|------|
| 3 | タスク内容 | @名前 | #channel | - |

### 📋 未分類（要確認）
- 内容が曖昧で判断できなかったメッセージ

---
合計: N件のタスク（高: X件, 中: Y件, 低: Z件）
取得期間: 直近 D 日間 | 対象チャンネル: N個
```

### 4. 補足情報

- SLACK_BOT_TOKEN 環境変数が未設定の場合、セットアップ手順を案内する
- メッセージが0件の場合は対象期間やチャンネルの変更を提案する
- スレッドの文脈も考慮して、タスクの完了/未完了を判定する
